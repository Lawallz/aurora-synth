#  Aurora Synthesizer

> **Seu estúdio de síntese e design sonoro direto no navegador.**

Inspirado na versatilidade de gigantes como o Zenology, o **Aurora** é um sintetizador web completo. Ele roda de forma 100% local e independente no seu browser, transformando o navegador em uma verdadeira *workstation* de áudio. Escolha seus timbres, adicione texturas e esculpa o som perfeito com processamento de sinal em tempo real.

---

##  Principais Recursos

*    **Biblioteca de Instrumentos:** Navegue por diferentes categorias e escolha o tipo de instrumento perfeito para a sua track.
*    **Rack de Efeitos (FX):** Molde seu som em tempo real com controles precisos de **Reverb**, **Chorus**, **Delay** e muito mais.
*    **Alta Performance:** Construído utilizando a Web Audio API nativa para garantir processamento rápido e latência mínima.
*    **100% Local:** Sem processamento na nuvem. Tudo acontece direto na sua máquina, garantindo total privacidade e funcionamento offline.

---

##  Como Executar Localmente

Para rodar o Aurora na sua máquina, você precisará do [Node.js](https://nodejs.org/) instalado.

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ````
3. Abra o link gerado no seu terminal (geralmente http://localhost:3000/) no seu navegador favorito e comece a criar!
