# Aurora - Painel de Engenharia de Áudio

Este projeto roda de forma 100% local e independente no navegador, utilizando a Web Audio API nativa para processamento de sinal em tempo real.

## Como Executar Localmente

**Pré-requisitos:** Node.js instalado na máquina.

1. Instale as dependências do projeto:
   `npm install`

2. Inicie o servidor de desenvolvimento local:
   `npm run dev`

3. Abra o link gerado no terminal (geralmente `http://localhost:5173/`) no seu navegador.
